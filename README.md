# 餐饮大亨 · Restaurant Tycoon

单机网页经营游戏：揣着 20 万从街边小店干起，一路开成国内连锁、全球餐饮集团，最后上市敲钟。**双击 `index.html` 即玩**，无需安装、无网络依赖，进度自动存在浏览器里。

## 玩法说明

**开局难度**（首局或重开时选择，随时决定整局手感）：

| 难度 | 本钱 | 客流 | 成本 | 对手 | 上市门槛 |
|---|---|---|---|---|---|
| 🌙 悠闲掌柜 | 30 万 | ×1.25 | ×0.92 | ×0.65 | 12 店 / 品牌 3.72 / 月均 24 万 |
| ☕ 创业之路 | 20 万 | ×1.00 | ×1.00 | ×1.00 | 15 店 / 4.00 / 30 万 |
| 🔥 存亡之战 | 18 万 | ×0.90 | ×1.03 | ×1.30 | 15 店 / 4.00 / 30 万（不降） |

困难模式的难点在经济和对手，不在终点——自动化通关机器人（质量优先策略）在 12 个随机种子下全部于 32~68 个月内上市，"决策好可以通关"有回归测试兜底（`node test/hard-win-test.js`）。

**核心循环**：月初做决策（定价、营销、排菜单、买设备、招人、扩张、研发）→ 点「下一个月」统一结算 → 看财报、处理随机事件和对手动作 → 循环。

**每月要操心的事**

- **定价**：6 档价位（乞丐→奢华）。价格越高客单价越高，但客人越少、对质量的要求越高。质量跟不上定价，评分会慢慢掉。
- **菜单**：菜品越多吸引力越高，但后厨负荷超过 100% 会拖慢出餐、拉低评分。研发出新菜记得上架。
- **设备**：灶具（效率+质量）、冷链卫生（食安+质量）、前厅（客单价+评分）、智能设备（省人力+接待）。外卖要先装打包台。
- **员工**：厨师撑质量，服务员撑接待，店长稳士气。每月招聘市场刷新，签下的人先进人才库，再调派到店。士气低了会撂挑子。
- **供应链**：便宜批发省成本但食安风险高，金穗冷链贵但品质稳。中央厨房建成后成本再降。
- **营销**：小店别乱烧钱（满座时营销是白烧的），需求吃不满接待力时再投，大城市回报更高。

**扩张路线**：本地市场（3 城）→ 国内市场（8 城，需 5 店 + 品牌 3.0 分）→ 海外市场（6 城，需国际化事业部 + 10 店 + 品牌 3.8 分）。开店可选招牌模式：直营全控全收，加盟只出 30% 装修费、总部抽 25% 流水，但品控会慢慢下滑（品控实验室可压制）。

**对手**：快栈（低价走量）、顶鲜（高端）、味霸（疯狂开店）、网红食验室（营销轰炸）会跟你抢城市、打价格战、挖你的人。资金够厚可以反过来把整家连锁买下来。

**钱不够**：可以贷款（额度=总资产一半，月息 1.2%），但现金连负 6 个月会被清算破产。

**终局**：15 家店 + 品牌 4.0 分 + 近 6 个月月均净利 30 万 → 上市敲钟（估值=年利润×PE，募资 25%），之后无尽模式继续玩。

## 设计参考（调研要点）

动手前查了一轮同类游戏的口碑机制与弃坑原因，本作对应落了这些设计：

- 菜单自由定制 + 顾客满意度核心（PlateUp!、Chef: A Restaurant Tycoon）→ 菜单工程：吸引力与后厨负荷互相牵制，评分 = 质量与定价期望的差值。
- 玩腻主因是"循环被摸透后难度停止进化、自动化让人变甩手掌柜"（Chef Life 晚期差评）→ 用随机事件抉择、对手动态、季节口味轮动持续打破固定循环；自动化只给到供应商/薪酬/广告这类琐事层，扩张与拍板永远留给玩家。
- PlateUp! 的"短周期目标 + 局间随机三选一"节奏 → 研发结题三选一、里程碑目标链（开店→盈利→连锁→国内→出海→上市）。
- 经济失衡致弃坑 → 前期单店月利几千到一万、设备/研发花钱有明确回报，数值用无头机器人 36~60 个月回归校准。

## 文件结构

```
restaurant-tycoon/
├── index.html        入口
├── data.js           全部数值与文案（调平衡改这里：BAL 经济参数 + DIFFS 难度表）
├── engine.js         纯逻辑引擎（无 DOM，node 可加载）
├── ui.js             界面渲染与交互
├── style.css         暖色深底主题
└── test/
    ├── balance-test.js   无头平衡回归（贪心机器人，36/60/120 月）
    ├── systems-test.js   系统级测试（解锁/加盟/并购/上市/破产/存档/难度/品控漂移）
    └── hard-win-test.js  通关验证（给定难度下好决策能上市）
```

## 测试

```bash
node test/balance-test.js              # 36 个月贪心机器人回归
node test/hard-win-test.js hard 120 7  # 困难模式通关验证（12 种子全 PASS）
node test/systems-test.js              # 系统级断言
```

浏览器里控制台还有调试句柄：`RT.st()` 看状态、`RT.jump(12)` 快进一年、`RT.cash(1000000)` 打钱。

## 调参入口

所有数值集中在 `data.js`：`DATA.BAL`（经济与公式参数）、`cities`（城市）、`cuisines` / `menuItems`（菜系菜品）、`equipment` / `upgrades`（设备与总部升级）、`events`（随机事件）、`rivals`（对手）。改完跑一遍上面的测试即可验证经济没被改崩。

存档键为 `restaurant-tycoon-save-v1`，重开新局或导入导出在游戏内右上角 💾 菜单。
